# 证件照背景替换工具 🖼️

这是一个简单易用的桌面应用程序，可以帮助您快速去除照片的背景，并替换为证件照常用的纯色背景（如红色、蓝色、白色）或蓝色渐变背景。

本工具通过调用 [Remove.bg](https://www.remove.bg/) 的 API 实现背景去除功能，操作直观，效果出色。

## ✨ 功能特性

-   **图形化界面**: 拥有简洁明了的用户界面，所有操作一目了然。
-   **本地图片选择**: 轻松从您的电脑中选择需要处理的图片。
-   **一键背景替换**: 自动识别并去除人物背景。
-   **多种背景可选**: 支持替换为透明、红色、蓝色、白色以及蓝色渐变背景。
-   **效果实时预览**: 在软件界面左右两侧分别展示原图和处理后的效果图。
-   **方便保存**: 处理完成后，可以轻松将结果保存为 PNG 格式的图片。

## 💻 使用要求

-   **操作系统**: Windows
-   **网络连接**: 需要连接互联网才能使用背景去除功能。
-   **API Key**: 需要一个来自 [Remove.bg](https://www.remove.bg/) 网站的 API Key。

## 🚀 如何使用

### 第一步：获取 API Key

1.  访问 [Remove.bg 官方网站](https://www.remove.bg/zh/api)。
2.  注册一个免费账户。
3.  登录后，在您的账户后台找到 API 相关的页面，点击 “Show API Key” 即可看到一长串字符，这就是您的 API Key。请复制它。

    > **注意**: Remove.bg 的免费账户每月提供一定数量的免费处理额度，通常足够个人使用。

### 第二步：运行程序

1.  下载 `证件照背景替换工具.exe` 文件。
2.  **（推荐）** 在 `.exe` 文件所在的文件夹中，创建一个名为 `apikey.txt` 的文本文档。将您复制的 API Key 粘贴到这个文件中并保存。这样做可以免去每次打开软件都输入 Key 的麻烦。
3.  双击运行 `证件照背景替换工具.exe` 程序。

### 第三步：操作流程

1.  **输入API Key**: 如果您没有创建 `apikey.txt` 文件，请将您的 API Key 粘贴到软件顶部的 “API Key” 输入框中。
2.  **选择图片**: 点击 **“选择图片”** 按钮，从您的电脑中选择一张人像照片。图片预览将显示在左侧的方框中。
3.  **选择背景色**: 在下拉菜单中，选择您想要的背景颜色（例如“蓝色”）。
4.  **执行替换**: 点击 **“替换背景”** 按钮。请稍等片刻，处理后的效果图将显示在右侧的方框中。
5.  **保存结果**: 如果对效果满意，点击下方出现的 **“保存结果”** 按钮，选择您想要保存的位置和文件名即可。

## ⚠️ 注意事项

-   本工具的核心功能依赖于 Remove.bg 提供的服务，请确保您的网络通畅。
-   处理效果的好坏取决于原始照片的质量，建议使用背景清晰、人物轮廓分明的照片以获得最佳效果。
-   请妥善保管您的 API Key，不要泄露给他人。
-   本程序仅为调用第三方API的图形化工具，请遵守 Remove.bg 的服务条款。
